Design Selection Guide — When Is Each Design Used?

▼
Design When to Use Key Features Typical Applications
CRD
Completely Randomized		 Experimental units are homogeneous; no known source of variability to block; environment is uniform. Treatments assigned completely at random to units. One error term. Simplest design; maximum error df. Laboratory assays, petri-dish experiments, greenhouse pots, tissue culture, any controlled uniform environment.
RCBD
Randomized Complete Block		 A known source of variability exists (fertility gradient, bench position, time, field edge). Blocking can remove it from error. Each block contains all treatments once. Two-way ANOVA without interaction (block × treatment). More precise than CRD when blocks are effective. Field trials with soil gradients, greenhouse benches, animal experiments, multi-location trials, repeated measurements.
Factorial
(2×3, 2×2, etc.)		 Two or more factors are studied simultaneously; interaction between factors is of interest. All combinations of factor levels are tested. Can be laid out in CRD, RCBD, or split-plot. Tests main effects and interaction. Agronomy (irrigation × nitrogen), plant breeding (genotype × environment), pest management (insecticide × variety).
Split-Plot One factor requires large plots (irrigation, tillage, mowing) and another factor can be applied to small sub-units. Randomization is restricted. Main plot factor randomized to large plots; sub-plot factor randomized within main plots. Two error terms (main-plot error and sub-plot error). Irrigation × variety, tillage × fertilizer, mowing × species, any design where one factor is hard to change.
Rule of Thumb: If the environment is uniform → CRD. If you can identify a gradient or grouping → RCBD. If you care about two factors and their interaction → Factorial. If one factor needs big plots and another can be applied to smaller units → Split-Plot.

Completely Randomized Design (CRD) — One-Way ANOVA

▼

When to Use CRD

  • Experimental units (plots, pots, petri dishes) are homogeneous — no gradient, no grouping.
  • The environment is uniform (lab bench, growth chamber, greenhouse).
  • Treatments are assigned to units completely at random.
  • Number of treatments is small and replicates are equal (or unequal).
📋 Experimental Setup
  • Treatments: 4 fertilizer formulations (T1, T2, T3, T4)
  • Response variable: Plant height at 6 weeks (cm)
  • Replicates: 5 per treatment → N = 20 experimental units
  • Design: CRD with 4 treatments, 5 replicates

🧮 Step-by-Step Manual Computation
Step 1 — Compute the Correction Factor (CF)
CF = G² / N = (500)² / 20 = 250,000 / 20 = 12,500
Step 2 — Compute Total Sum of Squares (Total SS)
Total SS = Σx² − CF Σx² = 22²+25²+24²+23²+26² + 28²+30²+29²+31²+27² + 20²+22²+19²+21²+23² + 26²+24²+27²+25²+28² = 2,890 + 4,215 + 2,215 + 3,390 = 12,710 Total SS = 12,710 − 12,500 = 210
Step 3 — Compute Treatment Sum of Squares (Treatment SS)
Treatment SS = Σ(Tᵢ² / n) − CF where n = 5 Σ(Tᵢ²/n) = 120²/5 + 145²/5 + 105²/5 + 130²/5 = 2,880 + 4,205 + 2,205 + 3,380 = 12,670 Treatment SS = 12,670 − 12,500 = 170
Step 4 — Compute Error Sum of Squares
Error SS = Total SS − Treatment SS = 210 − 170 = 40
Step 5 — Degrees of Freedom
Treatment df = t − 1 = 4 − 1 = 3 Error df = N − t = 20 − 4 = 16 Total df = N − 1 = 20 − 1 = 19
Step 6 — Mean Squares and F-Ratio
Treatment MS = 170 / 3 = 56.667 Error MS = 40 / 16 = 2.500 F = Treatment MS / Error MS = 56.667 / 2.500 = 22.67

Step 7 — Coefficient of Variation
CV = (√Error MS / Grand Mean) × 100 = (√2.500 / 25.0) × 100 = (1.5811 / 25.0) × 100 = 6.32% CV < 10% → excellent precision; 10–20% → good; > 20% → questionable
Step 8 — Least Significant Difference (LSD)
SE(d) = √(2 × Error MS / n) = √(2 × 2.5 / 5) = √1.0 = 1.000 LSD₀.₀₅ = t₀.₀₂₅,₁₆ × SE(d) = 2.120 × 1.000 = 2.12
📌 Interpretation
F = 22.67 > F₀.₀₁(3,16) = 5.29 → Reject H₀. There is a highly significant difference among the four fertilizer treatments (p < 0.01).

CV = 6.32% → Experimental precision is excellent.

Randomized Complete Block Design (RCBD) — Two-Way ANOVA

▼

When to Use RCBD

  • A known source of variability exists (soil fertility gradient, bench position, time of day, location).
  • That variability can be grouped into blocks that are internally more uniform.
  • The number of treatments is moderate (usually ≤ 15).
  • Each block contains all treatments once (complete blocks).
  • Block × treatment interaction is assumed negligible (no replication within blocks).
📋 Experimental Setup
  • Treatments: 5 tomato varieties (V1, V2, V3, V4, V5)
  • Response variable: Fruit yield (kg/plot)
  • Blocks: 4 blocks (based on soil fertility gradient)
  • Replicates: 1 per treatment per block → N = 20 plots
